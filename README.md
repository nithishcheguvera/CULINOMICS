# 🪙 CULINOMICS
### Culinary Meets Economics.
**Don't just run a restaurant. Run it intelligently.**

CULINOMICS is an intelligent restaurant management and business analytics platform designed to transform restaurant operations into actionable business intelligence.

By bringing financial insights, menu intelligence, predictive analysis, recipe information, and operational visibility into one unified ecosystem, CULINOMICS empowers restaurant owners and decision-makers to make smarter, data-driven decisions.

We believe that running a successful restaurant is not just about serving great food — it's about understanding the economics behind every dish, every order, and every business decision.

---

## ✨ Overview

Traditional restaurant management often involves disconnected information, manual calculations, limited financial visibility, and decisions based on intuition.

CULINOMICS aims to change that.

It provides a centralized platform where restaurant owners can explore business performance, understand menu profitability, evaluate dish combinations, analyze financial information, and make informed strategic decisions.

**One platform. Ten intelligent capabilities. Endless opportunities to grow.**

## 💻 Getting Started

Follow these steps to run CULINOMICS locally.

### Prerequisites

- Node.js (LTS recommended).
- npm or another compatible package manager.
- Git.

### Installation

**1. Clone the repository**

```bash
git clone <YOUR_REPOSITORY_URL>
```

**2. Navigate into the project**

```bash
cd CULINOMICS
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Visit:

```text
http://localhost:3000
```

### Production Build

To create a production build:

```bash
npm run build
```

To start the production server:

```bash
npm run start
```
